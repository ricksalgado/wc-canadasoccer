## 🌟 About The Project

This is a **personal project developed by Rick Salgado**. It is an engaging and immersive website dedicated to the Canadian National Men's Soccer Team's journey to the 2026 FIFA World Cup.

The application provides an interactive experience featuring 3D elements, dynamic animations, historical retrospectives, and an interactive match center.

---

## ✨ Features

- **Immersion Hero Section & 3D Trophy**: Experience a continuously spinning and dynamically zooming 3D World Cup Trophy powered by `@react-three/fiber` and `@react-three/drei`.
- **GSAP Animations**: Fluid and engaging reveal animations, staggered sequences, and a custom confetti particle emitter.
- **Dynamic Match Center**: Live scoreboard simulation with countdown timers and interactive elements.
- **Hype Meter (Hypometro)**: An interactive SVG gauge to measure fan excitement, culminating in a celebration when reaching 100%.
- **Comprehensive Roster**: Detailed player cards and modals featuring stats and bios.
- **Rich History Pages**: Newspaper-style editorial layouts covering World Cup history and Canada's milestones.
- **Interactive Navigation**: A sticky symmetrical header with glassmorphic effects and an architectural footer.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite
- **Styling**: Custom CSS/SCSS with glassmorphic designs
- **3D Graphics**: Three.js, React Three Fiber, React Three Drei
- **Animations**: GSAP (GreenSock Animation Platform)
- **Routing**: React Router DOM

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/yourusername/wc-canadasoccer.git
   ```

2. Navigate into the project directory
   ```bash
   cd wc-canadaSoccer
   ```

3. Install the dependencies
   ```bash
   npm install
   ```

4. Start the development server
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:5173`

---

## 📦 Build & Lint

To build the project for production:
   ```bash
   npm run build
   ```

To run the linter:
